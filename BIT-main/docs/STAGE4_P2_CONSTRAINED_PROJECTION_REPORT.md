# 阶段4 P2：受约束梯度投影候选优化报告

日期：2026-08-23

## 1. 方法

固定权重正则能够增加可行 LOO 候选，但会在部分事件牺牲 IoU。新优化器先计算
候选目标的实际 Adam 更新方向，再通过 Dykstra 循环投影到多个下降半空间：

    g_primary dot d >= 0
    g_pose dot d >= 0        （位姿约束超限时）
    g_temporal dot d >= 0    （时序约束超限时）

参数更新为 theta = theta - learning_rate * d。因此上述点积非负表示一阶近似下
对应指标不增加。投影作用于偏差修正和逐维预条件之后的实际 Adam 方向，避免
Adam 在投影后再次改变方向。

每一步记录活跃约束、梯度余弦、投影前后点积、方向范数和投影范数。实现位置：

- scripts/stage4_candidate_regularization.py；
- scripts/replay_stage4_p2_geometry.py；
- tests/test_stage4_candidate_regularization.py。

## 2. 训练 IoU 主梯度版本

第一版把训练 IoU 与 Laplacian 作为主梯度。225步中只有3步发生实际投影，说明
训练目标与最终控制帧选择指标未充分对齐。该版本保持7/9个 LOO 候选可行，
最终平均 IoU/位姿/时序分别改善0.000757/0.000596/0.000986，但严格改善仍为
6/15，未达到8/15，故否决。

## 3. 控制 IoU 对齐版本

第二版保留训练目标，同时以权重1加入控制帧平均 IoU，并将控制 IoU 梯度设为
投影主梯度。位姿与时序仍使用相对 same-run full 的 hinge 约束。开发参数：

- seed 59--64，两个问题序列，共15个事件；
- 25步候选优化；
- 每5步刷新12个 SE(3) 扰动方向；
- 20轮 Dykstra 投影；
- 约束激活阈值1e-8，投影可行容差1e-7。

结果如下：

| 指标 | 控制IoU对齐投影 |
|---|---:|
| LOO可行候选 | 8/9 |
| stable/full/LOO选择 | 1/6/8 |
| 严格改善事件 | 9/15（60%） |
| 严格改善seed | 6/6 |
| 平均Delta IoU loss | -0.002494 |
| IoU bootstrap 95% CI | [-0.003888, -0.001211] |
| 平均Delta位姿不一致性 | -0.000740 |
| 平均Delta时序标准差 | -0.001992 |
| IoU/位姿/时序逐事件退化 | 0/0/0 |
| 实际投影步数 | 17/225 |
| 一阶投影违规 | 0/225 |

所有冻结验收项均通过，状态为 screening_pass_pending_200_step_confirmation。

## 4. 边界与风险

控制帧参与了候选优化，因此本结果是开发证据，不是独立泛化证据。seed 68--70
仍未使用。平均扰动不确定性增加0.000392，虽然当前硬门控只约束位姿不一致性和
时序标准差，200步确认时仍需继续报告该指标。

## 5. 下一步

按冻结协议运行 seed 59--64 的200步确认，并将扰动方向刷新间隔改为1。只有
200步仍满足全部门槛，才冻结代码、参数与结果哈希并运行全新 seed 68--70。
