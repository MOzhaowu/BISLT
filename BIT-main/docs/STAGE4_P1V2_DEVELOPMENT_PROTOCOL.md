## P1-v2方法约束

- 父决策固定为确认v1中的`q_mask*q_pose`门控；
- 新模型只允许`accept -> downweight`，禁止升级决策或新增硬拒绝；
- 特征只使用当前帧和历史帧的对象无关诊断量；
- 正则化参数和降权阈值均在外层序列LOSO的内层选择；
- 内层安全非接受率必须≤50%，安全误拒率由父决策保持不变；
- 当前候选包括因果下降、轮廓残差空间分布和归一化Hessian退化特征。
