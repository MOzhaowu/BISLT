# 阶段4 P2：短时域全量/删一边际效用报告

日期：2026-08-23

## 1. 目标与冻结协议

本轮直接估计每个训练观测对验证几何的边际效用，避免把“失败概率高”误当成
“必然损害形状优化”。开发集固定为 seed 59–64；公式、步数、代码哈希和验收
条件冻结后，仅在全新的 seed 65–67 上执行一次独立验证，不依据独立结果调参。

冻结配置为 `config/stage4_p2_loo25_v1.json`。对每个候选事件执行：

1. 从同一初始模型进行 25 步全量短优化，得到验证 IoU loss `L_full`；
2. 逐一删除训练观测并进行相同的 25 步优化，得到 `L_loo_i`；
3. 定义边际效用 `u_i = L_loo_i - L_full`；
4. 对父门控未拒绝的观测使用
   `w_i = exp((u_i-max(u))/max(MAD(u),1e-8))`，父门控 reject 永久为 0；
5. 使用冻结权重执行 200 步完整几何优化，与同次 original 回放配对比较。

实现与评估位置：

- `scripts/stage4_influence.py`；
- `scripts/replay_stage4_p2_geometry.py`；
- `scripts/evaluate_stage4_p2_influence.py`；
- `tests/test_stage4_influence.py`；
- `tests/test_stage4_p2_influence_evaluation.py`。

## 4. 结论与研究含义

本轮交付了真正基于短步重优化的观测边际效用估计器，并完成了开发集冻结和全新
种子的独立验证。实验表明，25 步删一信号可以改善位姿一致性和跨验证帧稳定性，
但不能可靠预测其经过 200 步非线性优化后的 IoU 收益；短时域代理与长时域目标
之间仍存在明显错配。

因此作如下阶段判定：

- 短步 LOO v1 不冻结为在线权重；
- P2 的实验任务完成，但在线策略验收仍未通过；
- P3 继续阻塞；
- seed 65–67 已用于独立验证，后续不得重复作为独立测试集；
- 当前实现保留为可复现实验骨架和论文中的负结果/消融证据。

下一优先级不应继续在同一数据上搜索 softmax 温度。更有价值的路线是把边际效用
改为“更新是否被接受”的信赖域判据：先用短步 LOO 识别候选有害观测，再要求
真实验证损失单调下降才提交模型更新；新的策略必须重新定义开发集，并保留新的
未查看 seed 或对象作为最终测试集。
