## 1. 研究目标

U-BIT 在 BIT 的“位姿估计—模型生成—位姿更新”闭环中加入可观测性诊断、不确定性估计、观测门控、候选模型验证和回滚机制，抑制错误位姿或掩码造成的闭环误差放大。

核心研究假设是：只有可靠且具有新几何信息的观测才能参与形状更新；新模型只有在独立验证帧上优于当前稳定模型时才允许进入跟踪闭环。

## 3. 阶段0：基线冻结

### 改动位置

- `scripts/evaluate_baseline.py`：保留统一的 ADD-AUC、旋转、平移和 5°/5cm 指标。
- `scripts/create_run_manifest.py`：保存配置、环境、代码版本和输入规模。
- `scripts/check_run_completeness.py`：检查运行目录、帧数、指标字段和退出状态。
- `scripts/aggregate_results.py`：生成逐序列、对象级和总体汇总。
- `scripts/run_moped_baseline.sh`：在运行前后写 manifest，并执行完整性检查。

### 交付成果

每次运行目录至少包含：

```text
run_N/
├── run.log
├── exit_code.txt
├── elapsed_seconds.txt
├── manifest.json
├── raw/
├── metrics.json
└── diagnostics.csv
```

### 验收

1. 输入帧、GT帧和预测帧一致。
2. 所有指标均为有限数值。
3. 结果可追溯至配置文件摘要、Git提交和工作区状态。
4. 重复实验使用明确的 run number 和随机种子。

## 4. 阶段1：闭环可观测性诊断

### 改动位置

- `tracker/example/eg_BIT.cpp`：写出逐帧跟踪和关键帧诊断，不改变跟踪决策。
- `scripts/build_diagnostics.py`：合并 C++ 诊断、GT和预测位姿，生成可分析表格。
- `scripts/summarize_diagnostics.py`：报告漂移起点、模型更新附近误差和关键帧统计。

### 逐帧字段

- 帧号、模型版本；
- 跟踪耗时、success、valid；
- ROI位置和面积；
- 当前视角向量；
- 与已有模板视角的最小夹角；
- 是否参考帧、是否满足视角条件、是否发送给Python；
- 旋转误差、平移误差、5°/5cm是否成功（后处理生成）。

### 验收

1. 诊断行数与跟踪帧数一致。
2. 能自动找出首次超过 5°/50mm 的帧。
3. 能统计各模型版本前后的误差变化。
4. 诊断逻辑不改变原始 BIT 的位姿结果。

## 5. 阶段2–5的核心接口

后续阶段统一使用：

```python
q_i = q_mask * q_pose * q_visibility * q_information
```

观测按置信度划分为接受、降权和拒绝。候选模型使用独立验证帧计算：

```text
E_val(candidate) < E_val(stable) - epsilon
```

并同时满足尺度、质心、退化面和历史帧遗忘约束后才原子发布；否则拒绝并保留当前稳定模型。

## 6. 论文级实验协议

- 数据集：MOPED论文5对象、RBOT四类场景及人工遮挡/模糊/位姿扰动压力集。
- 准确度：ADD/ADD-S AUC、5°/5cm、旋转和平移误差。
- 稳定性：首次失败帧、连续跟踪长度、错误更新率、拒绝率和恢复率。
- 校准：NLL、ECE、置信区间覆盖率、failure AUROC。
- 效率：FPS、模型更新时间、峰值内存/显存和精度—延迟曲线。
- 统计：关键实验3–5次种子、95% bootstrap置信区间和配对检验。
