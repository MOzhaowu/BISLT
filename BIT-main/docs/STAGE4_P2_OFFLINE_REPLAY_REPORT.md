# 阶段4 P2：离线回放检查点报告

日期：2026-08-23

## 1. 结论

P2 已完成首轮“观测暴露回放 + 精确几何反事实回放”，但尚未达到阈值冻结条件。
冻结的 P1-v2 风险门控能显著减少危险观测进入训练，却没有稳定降低候选模型的
验证 IoU loss；当前不得进入 P3 在线接入。

本轮否决两项候选：

- 原始 P1-v2 软权重：仅 4/7 个可优化事件改善 IoU，平均变化为 +0.000459；
- 0.50 权重下限：仅 2/7 个事件改善，平均变化为 +0.001441，劣于原软权重。

## 3. 冻结门控再评估

6 个运行产生 339 个位姿帧，其中真实失败 162 帧；预热后与掩码概率严格对齐
18 个关键帧，包含 4 个危险帧和 14 个安全帧。

| 指标 | 父门控 | P1-v2 |
|---|---:|---:|
| 危险保护率 | 50.0% | 100.0% |
| 安全误拒率 | 7.14% | 7.14% |
| 安全非接受率 | 42.86% | 57.14% |

P1-v2 的危险保护方向正确，但安全非接受率超过预注册的 50% 上限。这一小样本
结果不能推翻之前的独立再确认，但足以阻止本轮在线阈值冻结。

## 4. 观测暴露消融

8 个候选事件中有 3 个记录候选相对稳定模型退化。

| 策略 | 危险暴露下降 | 安全暴露下降 | 阻断候选 |
|---|---:|---:|---:|
| P1-v2 soft | 93.45% | 27.45% | 1/8 |
| soft floor 0.25 | 75.00% | 25.98% | 1/8 |
| soft floor 0.50 | 50.00% | 23.01% | 1/8 |
| soft floor 0.75 | 25.00% | 17.47% | 1/8 |
| hard non-accept | 100.00% | 45.45% | 2/8 |

0.50 下限满足“危险暴露至少降低 50%”的筛选条件，因此进入精确几何消融；
0.25 和 0.75 不再做结果导向的多重搜索。

## 5. 精确几何反事实回放

原策略重优化与在线记录候选的最大绝对 IoU loss 差为 0.003009。该误差主要来自
自定义 CUDA 光栅化反向传播的非完全确定性，已与策略效应同量级。因此结论以同次
回放内的配对差异为主，不把记录候选差异解释为策略增益。

| 策略 | 可优化/总事件 | IoU改善事件 | 平均 ΔIoU loss | 优于记录稳定模型 |
|---|---:|---:|---:|---:|
| P1-v2 soft | 7/8 | 4/7 | +0.000459 | 4/7 |
| soft floor 0.50 | 7/8 | 2/7 | +0.001441 | 4/7 |
| hard non-accept | 6/8 | 2/6 | +0.000682 | 3/6 |

负值才表示 IoU loss 改善。三个策略的平均值均为正，因此都未通过。

在有效验证帧不少于 2 的事件上，P1-v2 soft 的平均位姿不一致性下降
0.000215，但平均 IoU loss 上升 0.000743，时序标准差基本不变。0.50 下限虽使
位姿不一致性下降更多，却同时增加 IoU loss 与时序波动，说明“风险概率越高就
越小权重”的单调规则没有等价地刻画观测对形状优化的实际贡献。

## 6. 阶段判定

- P2 首轮离线回放管线：完成；
- P2 在线权重/阈值冻结：未通过；
- 0.50 权重下限：否决；
- P3 在线影子接入：继续阻塞；
- 当前代码与归档：保留为后续方法实验骨架。

## 7. 下一最高优先级

下一步不再继续搜索固定下限，而是建立“观测风险”到“验证损失影响”的因果桥梁：

1. 对每个候选训练观测计算梯度对齐或近似 leave-one-out influence；
2. 区分“位姿高风险但对几何仍有信息”与“确实拉坏验证几何”的观测；
3. 在 seed 59–61 上冻结权重映射和正则化；
4. 用未查看的 seed 62–64 独立验证；
5. 只有安全非接受率不超过 50%、错误更新下降至少 50%，且三个种子方向一致，
   才允许冻结 P2 并进入 P3。

该路线直接针对本轮发现的研究空白：分类失败概率具有风险排序能力，但不是形状
优化中单个观测边际效用的可靠代理。
