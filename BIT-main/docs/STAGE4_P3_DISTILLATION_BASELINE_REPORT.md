# 阶段4 P3：离线教师蒸馏首轮基线报告

日期：2026-08-24

## 1. 目标与数据隔离

阶段4 P2冻结方法每个事件仍需要短步LOO和三候选验证，独立验证中的平均边际
效用计算约24.3秒/事件，不能直接在线运行。本阶段把P2作为离线教师，拟合两个
低成本学生头：

1. 观测效用头：预测每个训练观测的教师边际效用和keep/drop标签；
2. 事件安全头：预测正常full候选是否比stable更差。

学生输入仅包含在线可获得的`q_mask`、`q_pose`、可见性、信息量、Hessian相对
特征、轮廓残差和事件缓冲规模。对象、序列、seed、GT标签、验证损失、LOO效用
和教师选择均禁止作为输入。

seed 59--64作为开发教师数据。seed 68--70保持为P2报告专用独立证据，禁止用于
学生训练、特征选择、正则选择或阈值调整。

## 3. 固定逻辑回归基线

在没有调参的前提下，使用固定L2=1.0的平衡逻辑回归。外层严格按
`object/sequence`留一，同一序列所有seed始终同折。由于只有两个序列组，当前
无法进行可识别的嵌套LOSO，正则值不得根据本轮结果调整。

| 学生头 | OOF AUROC | Accuracy | Balanced accuracy | Brier |
|---|---:|---:|---:|---:|
| 观测keep/drop | 0.354 | 0.594 | 0.483 | 0.366 |
| full有害性 | 0.364 | 0.333 | 0.386 | 0.573 |

观测头在两个外层折的AUROC分别为0.227和0.386，说明当前特征—标签关系不能从
一个问题序列迁移到另一个问题序列。事件安全头留出`duplo_dude/01`时AUROC为
0.778，但留出`toy_plane/02`时只有一个正例，AUROC为0.5；跨折概率尺度漂移使
总体OOF AUROC进一步下降。

## 4. 判定

首轮学生基线不通过，不能进入P3在线影子部署。当前瓶颈是教师序列组和混合标签
事件不足，而不是需要继续搜索逻辑回归正则。只增加相同两个序列的seed会增加
相关样本，却不能解决对象/序列外推不可识别问题。

下一优先级是按冻结清单扩充教师对象/序列组：补充
`black_drill/00`、`cheezit/00`、`cheezit/02`、`cheezit/04`、
`duplo_dude/02`和`toy_plane/03`，并保留现有`duplo_dude/01`与
`toy_plane/02`。扩样阶段使用seed 71--73；seed 74--76保留为学生公式确认，
外部对象和seed 77--79继续锁定为独立验证。

只有至少8个序列组具备混合keep/drop和full安全/有害事件后，才允许进行嵌套
LOSO模型与正则选择。学生独立验证通过且实测在线额外开销低于5%后，才进入
P3影子记录。
