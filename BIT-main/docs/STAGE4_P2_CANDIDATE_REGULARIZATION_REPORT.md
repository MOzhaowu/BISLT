# 阶段4 P2：候选多指标可行域正则报告

日期：2026-08-23

## 1. 实现

LOO 候选的几何优化目标扩展为：

    L = L_train_iou + 0.1 L_laplacian
      + lambda_pose R_pose + lambda_temporal R_temporal

R_pose 使用与门控完全相同的12个有符号 SE(3) 扰动，惩罚邻域扰动比名义位姿
更优的 IoU loss 增益；R_temporal 为逐控制帧 IoU loss 的总体标准差。扰动
方向先无梯度扫描，再只重渲染活跃方向反传，等价于分段 min 的梯度且避免
12*N 个软栅格图同时保留计算图。

stable 和原 full 候选保持不变。正则只改变 LOO 候选，之后仍由冻结的多指标
信赖域从 stable/full/LOO 中选择，full 永远是保底候选。实现位于：

- scripts/stage4_candidate_regularization.py；
- scripts/replay_stage4_p2_geometry.py；
- scripts/apply_stage4_p2_multimetric_trust_region.py。

## 2. 数据隔离边界

现有15个开发事件中，12个事件没有第三组可与训练帧、控制帧同时隔离的历史帧。
因此第一版先在训练支持帧优化绝对正则；第二版在候选控制帧优化相对 full 的
超限 hinge，但不把控制帧平均 IoU 加入优化目标。

第二版控制帧不再是严格 held-out 数据，只能作为 seed 59--64 的方法开发证据。
任何泛化结论必须来自从未使用的 seed 68--70；这三个 seed 本轮未运行。

## 3. 25步预注册筛选

| 方案 | LOO可行事件 | 平均Delta IoU | 平均Delta位姿 | 平均Delta时序 |
|---|---:|---:|---:|---:|
| 训练帧绝对正则 vs 控制 | 4/9 | +0.000440 | +0.000116 | +0.000192 |
| 相对full控制帧hinge vs 控制 | 7/9 | -0.000086 | +0.000220 | -0.000367 |

第一版未提高可行率且三个主指标均退化，已否决。第二版把可行率从44.4%提高到
77.8%，同时改善 IoU 和时序，但 LOO 原始候选的平均位姿不一致性增加，因此没有
通过预注册的200步推进条件。

把第二版25步候选送入冻结多指标选择器后，stable/full/LOO选择为2/9/4：

- 最终 IoU、位姿、时序逐事件均零退化；
- 平均 IoU loss 相对 full 改善0.000677；
- bootstrap 95% CI 为 [-0.001267, -0.000202]；
- 平均位姿不一致性改善0.000401；
- 平均时序标准差改善0.000723；
- 5/6个 seed 严格改善，其余不退化；
- 严格改善事件为6/15（40%），仍低于冻结要求的50%。

因此总体 pass=false，不运行200步确认，也不启动 seed 68--70。

## 4. 结论与下一步

本轮证明可微相对约束确实能让更多 LOO 候选主动进入多指标可行域，并将严格改善
seed 从原多指标门控的3/6提高到5/6；瓶颈已从“多数LOO不可行”转为“可行候选的
IoU收益不足以在至少一半事件胜过full”。

下一优先级不是放宽门控，而是加入受约束梯度投影或增广拉格朗日：只接受同时满足
位姿/时序约束且与训练 IoU 梯度不冲突的正则更新。开发目标仍为至少8/15事件严格
改善；通过后再做200步精确扰动刷新和 seed 68--70 独立验证。
