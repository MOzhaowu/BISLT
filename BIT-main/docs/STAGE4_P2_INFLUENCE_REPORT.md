# 阶段4 P2：观测边际效用与独立验证报告

日期：2026-08-23

## 1. 研究问题

阶段2/3输出的是“观测失败概率”，但形状优化真正需要的是“该观测进入训练后会
怎样改变验证几何”。两者不等价。本轮建立验证梯度驱动的观测边际效用，目标是
保留风险较高但对几何有帮助的观测，同时压低标签安全但会拉坏验证几何的观测。

## 2. 方法

### 2.1 一阶影响

在冻结稳定几何处计算验证损失梯度 `g_v` 和每个训练观测梯度 `g_i`。一步梯度
更新的一阶近似为：

`delta L_validation ~= -learning_rate * dot(g_v, g_i)`

正点积表示观测预计降低验证损失，负点积表示预计产生有害更新。实现同时记录
cosine、原始点积、梯度范数和计算耗时。

### 2.2 风险先验非负梯度匹配

简单的正对齐救回策略在开发集仅改善 1/7 个事件，因此被否决。最终冻结策略解
如下带风险先验的非负岭回归：

`min ||G_normalized*w-g_validation_normalized||^2 + ||w-w_risk||^2`

约束为 `0 <= w <= 1`，ridge 固定为 1。父门控 reject 的观测永久锁为 0；
其余观测由梯度匹配调整。没有对象特定权重，也没有在独立种子上调参。

冻结配置：

- `config/stage4_p2_gradient_match_v1.json`。

15 个严格对齐关键帧和 7 个候选事件。

## 5. 阶段结论

本轮完成了“风险概率”到“几何边际效用”的可运行技术桥梁，并证明梯度匹配在
开发集有信号、能改善位姿一致性；但其最终 IoU 和时序收益没有通过独立验证。
因此：

- 梯度匹配 v1 不冻结为在线权重；
- P2 在线策略仍未通过；
- 不进入 P3；
- seed 62–64 已经使用，后续不得再次作为独立验证集。

## 6. 下一研究优先级

下一版应使用短时域近似 leave-one-out，而不是稳定点的一阶梯度：

1. 在每个候选上进行短步全量优化和逐观测删一优化；
2. 用 `L_validation(leave-one-out_i)-L_validation(full)` 估计边际效用；
3. 检查其与完整 200 步真实效应的相关性，并报告额外开销；
4. 在 seed 59–64 只做开发与公式冻结；
5. 冻结后使用全新 seed 65–67 独立验证。

若短时域 LOO 仍不能稳定改善，研究结论应转向“离线安全审计/拒绝错误更新”，
而不是继续宣称可实时加权。
