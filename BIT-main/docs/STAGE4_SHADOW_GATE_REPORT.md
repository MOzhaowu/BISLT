# 阶段4首版报告：q_mask/q_pose影子门控

日期：2026-08-22

## 结论

阶段4已经进入P0影子门控。当前实现只记录“接受、降权、拒绝”建议，不改变BIT
关键帧发送、模型训练、跟踪位姿或模型发布，因此可以安全评估风险分数是否具有
门控价值。

冻结的`q_mask`与`q_pose`在83个可对齐关键帧上的联合风险AUROC为0.854。
按对象/序列留一选择阈值后，拒绝组的危险观测比例达到92.1%，高于降权组的
60.9%和接受组的36.4%，说明门控分组具有清晰的风险单调性。但安全帧误拒率
仍为11.5%，且跨序列阈值存在漂移，当前版本尚不具备直接上线条件。

## 数据和无泄漏协议

- 阶段2输入：Mask IoU<0.90冻结OOF失败概率；
- 阶段3输入：5°/5cm冻结OOF失败概率；
- 对齐结果：83个关键帧、8个序列、seed 41/42/43；
- 同一对象/序列的三个seed保持同折；
- 阈值在外层留出序列之外的数据上选择；
- 外层序列仅用于评价门控决策。

联合可靠度定义为：

```text
q_mask = 1 - p_mask_failure
q_pose = 1 - p_pose_failure
q_base = q_mask * q_pose
```

`q_visibility`与`q_information`已经记录为审计特征，但不参与首版主决策，避免
阶段3已发现的跨对象概率漂移污染冻结门控基线。

## 首轮固定阈值负向控制

首轮使用`accept=0.80`、`reject=0.30`验证完整管线：

| 指标 | 结果 |
|---|---:|
| 风险AUROC | 0.854 |
| 接受/降权/拒绝 | 0 / 18 / 65 |
| 危险帧非接受覆盖率 | 100% |
| 危险帧拒绝召回 | 89.5% |
| 安全帧误拒率 | 53.8% |

该策略虽然能覆盖危险帧，但没有接受任何关键帧，会使形状更新停滞，因此只能作为
过度保守的负向控制，不能上线。

## 阈值LOSO结果

训练折约束：安全帧拒绝率不超过10%，安全帧非接受率不超过50%。在满足约束的
候选中，最大化危险帧拒绝召回并兼顾降权覆盖。

| 指标 | LOSO结果 |
|---|---:|
| 接受/降权/拒绝 | 22 / 23 / 38 |
| 危险帧拒绝召回 | 61.4% |
| 危险帧非接受覆盖率 | 86.0% |
| 安全帧误拒率 | 11.5% |
| 安全帧非接受率 | 46.2% |

各决策组结果：

| 决策 | 帧数 | 当前危险观测率 | 未来5帧至少一次位姿失败 |
|---|---:|---:|---:|
| 接受 | 22 | 36.4% | 77.3% |
| 降权 | 23 | 60.9% | 91.3% |
| 拒绝 | 38 | 92.1% | 91.9% |

当前危险率呈现`接受 < 降权 < 拒绝`的预期单调关系。未来失败率在降权和拒绝组
之间差异很小，且接受组仍然偏高，说明当前分数更适合判断“当前观测能否参与模型
更新”，尚不足以独立预测序列未来是否持续跟踪失败。

## 跨序列稳定性

外层折选择的接受阈值为0.20–0.30，拒绝阈值为0.075–0.10。多数序列集中在
`accept=0.25/reject=0.075`附近，但存在两个明显问题：

- `duplo_dude/01`：危险帧保护率为0，安全帧误拒率33.3%；
- `toy_plane/02`：危险帧均未被硬拒绝，安全帧误拒率20%。

因此不能直接冻结一个全局阈值。下一步需要优先验证对象无关可见性/信息量特征
能否修复这两个外层折，同时保持其他序列的安全帧保留率。

## 模型更新事件分析边界

83个关键帧中有46个可关联到后续10帧内的模型重载，但“明确错误更新”只有3个，
分别落在接受、降权、拒绝组各1个。该样本量不足以评价“错误更新减少50%”这一
阶段验收指标。需要在影子模式下扩大关键帧及真实更新事件样本，或进行可复现的
离线更新回放。
