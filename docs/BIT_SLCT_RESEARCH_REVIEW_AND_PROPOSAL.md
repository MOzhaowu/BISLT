# BIT 与 SLCT 研究审查及论文级改进方案

## 1. 审查范围与结论

本报告审查以下项目：

- `/Users/bytedance/Desktop/SLCT-main`
- `/Users/bytedance/Desktop/BIT-main`
- BIT 的 CVPR 2025 论文及公开实验结果
- 2024-2026 年未知物体 6DoF 跟踪、在线重建、不确定性建模和主动视角选择相关工作

两个源码目录均不包含 `.git`，因此无法确认提交历史、论文版本标签和未提交改动。本报告的代码结论只对应当前目录快照。

核心判断：

1. SLCT 是已知 CAD 模型条件下的单目 RGB 区域/轮廓 6DoF 跟踪器，研究贡献是利用搜索线上的轮廓约束构造像素级权重，提高歧义颜色和局部遮挡下的鲁棒性。
2. BIT 不是对 SLCT 的简单封装，而是以 SLCT/SLOT 为姿态模块，增加 SAM 分割、Soft Rasterizer 网格反演和跟踪关键帧反馈，形成“几何改善跟踪、跟踪改善几何”的双向闭环。
3. BIT 已经形成明确且有价值的研究范式，并以 CVPR 2025 Highlight 发表。最强贡献是把无 CAD、无对象特定训练的 RGB 跟踪转化为在线构建模型后的模型驱动跟踪。
4. 当前实现与实验协议仍不能严格证明长期自主跟踪能力。RBOT 协议在失败后使用当前帧 GT 重置，BIT 运行时也用 GT 判断失败并恢复；这会截断漂移，掩盖错误传播和重定位能力不足。
5. 当前闭环是确定性的、等权的和不可拒绝的。错误 Mask、错误姿态和低信息视角均可能进入几何更新，更新后的错误模型又会反馈给跟踪器，形成典型的错误自增强。
6. 最具论文价值且可落地的下一步不是直接替换为 3DGS，而是研究“可靠的双向迭代”：显式建模观测、位姿和几何不确定性，以信息增益选择证据，并在遮挡后依靠长期记忆恢复。

建议主线为 **P-BIT: Probabilistic Bidirectional Iterative Tracking**。它围绕一个统一问题展开：

> 在未知刚性物体的单目 RGB 在线跟踪与重建中，如何量化并阻断跟踪误差和建模误差的双向传播，使系统在无 GT 恢复条件下仍能长期运行、校准风险并从遮挡中恢复？

## 2. SLCT 现有研究分析

### 2.1 研究问题

SLCT 面向已知三维模型、已知相机内参和首帧位姿的单目 RGB 6DoF 跟踪。它重点处理两类传统区域跟踪难题：

- 前景与背景颜色相近，区域概率缺乏判别性。
- 部分遮挡或背景杂乱导致轮廓附近出现错误响应。

### 2.2 技术路线

主要链路如下：

1. 使用当前三维模型和姿态渲染轮廓、深度和对象 Mask。
2. 在投影轮廓上采样搜索线。
3. 使用局部前景/背景颜色直方图计算搜索线各像素的区域概率。
4. 搜索最可能的真实轮廓点，并根据颜色一致性和轮廓距离计算像素权重。
5. 将权重加入区域能量的 Jacobian 与近似 Hessian。
6. 通过多尺度、由粗到细的迭代优化 6DoF 位姿。
7. 使用新姿态更新时序一致的局部颜色直方图。

相关源码证据：

- `src/mbt/search_line.cc`：轮廓提取、搜索线和法向生成。
- `src/mbt/tracker_slc.cc`：轮廓点搜索、颜色/距离权重、Jacobian 和多尺度优化。
- `src/mbt/tclc_histograms.cc`：时序一致局部颜色直方图。
- `src/app/run_on_video.cc`：数据读取、初始化、评测和 GT 失败恢复。

### 2.3 原始创新点

SLCT 的方法创新是连贯的：

- 用轮廓搜索线替代全图 signed distance transform，缩小计算与匹配范围。
- 通过局部前景/背景概率寻找显式轮廓对应点。
- 将轮廓对应的颜色可信度和几何距离转化为像素级权重。
- 在区域能量内抑制遮挡、相似颜色和背景杂波造成的错误梯度。

公开论文指出该方法在复杂场景，尤其局部遮挡与颜色歧义下优于同期区域跟踪器。[来源](https://pubmed.ncbi.nlm.nih.gov/34077359/)

### 2.4 工程实现与论文可信度风险

1. `tracker_mode` 实际未生效。`src/mbt/tracker.cc:38-46` 无条件创建 `SLCTracker`，配置中的模式注释容易产生错误实验归因。
2. `bench_mode` 会改变算法状态。`src/app/run_on_video.cc:83-89` 使用当前帧 GT 判断失败并立即恢复，不是纯离线评价。
3. 失败率因此表示“单帧局部跟踪成功率”，不是不干预条件下的序列生存率。
4. `ColorWeight()` 在首个 `return` 后仍有不可达公式，说明不同权重形式未被清晰版本化。
5. 当前目录没有单元测试、回归测试、固定环境文件或完整结果制品。
6. 配置示例含 Windows 绝对路径，复现需要较多人工修改。

### 2.5 SLCT 的研究定位

SLCT 适合作为：

- BIT 的轻量、可解释、无需训练的姿态优化器。
- 对比“已知精确模型”和“在线生成模型”的受控跟踪基线。
- 提取轮廓残差、Hessian 条件数、有效搜索线比例等不确定性信号的基础。

它不适合直接承担：

- 完全遮挡后的全局重定位。
- 大位移或长时间离开视野后的恢复。
- 无 CAD 条件下的初始化与几何推断。
- 对称物体的多模态位姿表达。

## 3. BIT 现有研究分析

### 3.1 研究问题与任务假设

BIT 研究未知刚性物体的单目 RGB 6DoF 跟踪。它不要求目标 CAD 模型，也不进行对象特定或数据集特定训练，但仍需要：

- 相机内参。
- 首帧目标框。
- 首帧初始 6DoF 位姿。
- 可选参考帧及其位姿。

因此，“prior-free”应严格解释为“无目标 CAD 和无对象特定训练先验”，不能解释为无初始化信息。

### 3.2 技术路线

BIT 的闭环为：

1. 从固定球形网格开始。
2. 使用目标框提示 SAM 得到轮廓。
3. 在给定位姿和内参下用 Soft Rasterizer 渲染网格轮廓。
4. 优化轮廓 IoU 与 Laplacian 正则，使球形网格逼近目标。
5. 将网格缩放后交给 C++ SLCT/SLOT 跟踪。
6. 根据新视角与历史视角的夹角选择关键帧。
7. 把 RGB、概率图、Mask、位姿、内参和 ROI 写入磁盘。
8. Python 使用新增帧再次优化网格。
9. C++ 加载新网格，继续跟踪，最多迭代三轮。

关键实现：

- `examples/run_example.py:89-138`：固定拓扑网格参数化。
- `examples/run_example.py:285-312`：轮廓 IoU 加 Laplacian 的模型优化。
- `examples/sam_utils.py:185-207`：SAM 多候选推理，但固定使用 `masks[0]`。
- `tracker/example/eg_BIT.cpp:72-102`：基于视角夹角的关键帧筛选。
- `tracker/interface/tracker_summer/tracker_summer.cc:149-196`：SLCT 跟踪、概率图和观测生成。
- `tracker/interface/communication.cpp:316-331`：C++ 向 Python 发布多模态文件。

### 3.3 已发表创新贡献

BIT 的已有贡献包括：

1. 提出无 CAD、无对象特定训练的 RGB 6DoF 跟踪任务设定。
2. 构建几何生成与姿态优化相互促进的双向迭代框架。
3. 使用简单球形先验和轮廓反演快速生成可用于跟踪的显式网格。
4. 生成模型可脱离 BIT，被其他模型驱动跟踪器复用。

CVPR 论文报告：

- MOPED 五个对象上，无参考帧 `Ours(0)` 的平均 ADD-AUC 为 74.2；三参考帧 `Ours(3)` 为 86.2。
- RBOT 上，3/6/12 参考配置的归一化 Hausdorff 距离分别为 0.035/0.011/0.010。
- 生成模型可用于 RBOT、SLOT、Song23、RBGT、SRT3D 等跟踪器。
- 640x480 下跟踪约 30 ms/帧；6 个参考帧加 12 个关键帧时，每轮建模约 10 秒。

论文与源码均支持“几何质量提高会改善模型驱动跟踪”这一核心结论。[CVPR 论文页](https://openaccess.thecvf.com/content/CVPR2025/html/Song_Prior-free_3D_Object_Tracking_CVPR_2025_paper.html)

### 3.4 实验设计优点

- 同时覆盖真实 MOPED 和包含动态光、噪声、遮挡的 RBOT。
- 区分无参考帧和有参考帧设定。
- 除位姿精度外，还用归一化 Hausdorff 距离评价生成模型。
- 将生成模型输入多个外部跟踪器，验证表示的可复用性。
- 报告了迭代次数、关键帧数、模型精度和运行时间。

### 3.5 实验设计的关键缺口

#### 3.5.1 GT 恢复改变了被评价算法

论文明确规定 RBOT 中超过 5 cm 或 5 度即判失败，并将姿态重置为 GT。源码也执行该逻辑：

- `tracker/example/eg_BIT.cpp:245` 每帧把 GT 注入 `StdData`。
- `tracker/interface/tracker_base.cc:125-196` 用 GT 计算在线成功状态。
- `tracker/interface/tracker_summer/tracker_summer.cc:180-185` 失败后 `setPose(currData->gt)`。
- SLCT 原项目在 `src/app/run_on_video.cc:83-85` 执行同类恢复。

这不构成论文造假，因为协议已公开，但会限制结论范围：

- 无法评价首次失败之后的误差传播。
- 无法评价长期自主跟踪和重定位。
- 生成关键帧的姿态可能间接受到 GT 恢复影响。
- “全序列成功率”实质上是带 oracle recovery 的逐帧局部成功比例。

后续论文必须同时报告：

- `oracle-reset`：复现原论文。
- `strict-causal`：仅首帧使用 GT，之后 GT 只离线计算指标。

#### 3.5.2 通信协议存在确定性竞态

- C++ 按 `img -> prob -> mask -> ROI -> size -> K -> pose` 写入。
- Python 仅以 `K` 文件数量判断批次就绪。
- 因此 Python 可能在 pose 尚未完成时开始读取。
- Python 又按各目录排序后的位置切片，不按帧 ID 求交集；单个文件缺失会造成跨模态错配。
- `SentDatas2Py()` 忽略各写入返回值并始终返回 `true`。

这会直接破坏训练/优化数据的对应关系，是当前最高优先级工程问题。

#### 3.5.3 观测质量没有进入闭环

- SAM 返回三个 Mask 和分数，但代码固定使用 `masks[0]`。
- 轮廓、概率图、位姿和关键帧在几何优化中等权。
- `flatten_loss` 被计算但未进入总损失。
- 保存最后一次优化状态，而不是验证集上的最佳状态。
- 新模型无质量门控、无版本回滚。
- 关键帧只按 3 度视角阈值和边界条件筛选。

#### 3.5.4 表示能力受固定球形拓扑限制

固定拓扑只能连续形变：

- 不能生成孔洞、环形结构和多个连通分量。
- 轮廓监督对凹陷和不可见表面几乎没有约束。
- 单目轮廓下尺度、深度、对称性和背面几何存在不可辨识性。
- Laplacian 平滑会进一步偏向圆滑、保守的形状。

#### 3.5.5 复现与统计证据不足

- 仓库不保存论文结果表、逐帧日志和统一评测脚本。
- 没有置信区间、重复运行方差或显著性检验。
- MOPED 只选 5 个相对可靠对象，需报告选择规则和全量敏感性分析。
- 当前代码含 GUI 阻塞、固定临时文件和未检查 I/O，难以稳定批量运行。
- README 声明 Soft Rasterizer 存在微小随机性，但未给出重复运行误差范围。

## 4. 领域趋势与机会

截至 2026 年，相关前沿集中在：

1. **未知对象联合跟踪与重建**：从已知 CAD 跟踪转向模型自由、在线建图和开放世界目标。
2. **长期对应与遮挡恢复**：使用 2D point tracker、特征记忆或图优化跨越完全遮挡。Point2Pose 展示了长程点对应、图优化和在线 TSDF 对未知对象恢复的价值，但使用 RGB-D。[来源](https://arxiv.org/html/2604.10415v1)
3. **不确定性感知优化**：WildGS-SLAM 和 USplat4D 均表明，对观测或几何元素显式赋予不确定性可减轻动态干扰、遮挡漂移和错误建图。[WildGS-SLAM](https://wildgs-slam.github.io/)；[USplat4D](https://arxiv.com/abs/2510.12768)
4. **对象级信息增益**：主动重建从简单视角距离转向可见性、Fisher 信息或参数协方差驱动的选择。[SBV](https://arxiv.org/html/2405.02568v3/)；[OUGS](https://arxiv.org/html/2511.09397v2)
5. **显式高效表示**：3DGS 提供高效可微渲染和外观建模，GTR 已用于未知对象跟踪与重建，但依赖 RGB-D。[来源](https://arxiv.org/html/2505.11905)
6. **视频基础模型**：SAM 2 将单帧提示分割扩展为带记忆的视频分割，可减少逐帧 Mask 跳变，但其输出仍需几何一致性校验。[来源](https://ai.meta.com/blog/segment-anything-2-video/)

研究机会不在于重复这些模块，而在于利用 BIT 的独特闭环，研究“误差何时能被另一模块纠正，何时会被放大”的可验证机制。

## 5. 主推荐方案：P-BIT

### 5.1 研究问题

给定单目 RGB 序列、相机内参、首帧目标框和首帧位姿，在无 CAD、无对象特定训练、无后续 GT 干预条件下：

1. 如何联合表示分割歧义、位姿歧义和未观测几何的不确定性？
2. 如何只让可靠证据进入几何更新，避免模型污染？
3. 如何选择真正降低几何/位姿后验熵的关键帧？
4. 如何在完全遮挡或短时跟踪失败后，从长期对象记忆恢复？
5. 不确定性是否校准，能否提前预测失败，而不只是提高平均精度？

### 5.2 核心假设

H1：BIT 的主要误差来源不是单个模块的平均精度，而是低质量观测在闭环中的累积放大。

H2：由 SAM 候选分歧、SLCT 轮廓统计、可微渲染残差和位姿 Hessian 共同估计的异方差不确定性，比任一单独分数更能预测姿态误差。

H3：以期望信息增益替代视角夹角，可以用更少关键帧获得更好的跟踪和几何。

H4：长期二维点/特征记忆与当前生成几何联合使用，可在不依赖 GT 的情况下恢复遮挡后的 6DoF 位姿。

### 5.3 预期创新贡献

#### C1. 概率双向迭代框架

将原始交替优化改写为带不确定性的后验更新：

`p(G, T_1:t, Z_1:t | I_1:t, K)`

其中：

- `G`：对象几何及每个几何元素的置信度。
- `T_t`：SE(3) 位姿及协方差。
- `Z_t`：分割候选隐变量。
- `I_t`：RGB 观测。

关键不是求精确全后验，而是构建可在线近似、可校准、可拒绝更新的因子化模型。

#### C2. 多候选分割与位姿联合证据

对每个 SAM/SAM 2 候选 `M_t^k` 计算：

- SAM 预测质量。
- 与 SLCT 前景概率图的一致性。
- 与当前几何渲染轮廓的一致性。
- 与长期点轨迹可见区域的一致性。
- 面积、连通性和时间变化先验。

不立即硬选单个 Mask，而保留 Top-K 权重：

`q(Z_t=k) = softmax(-E_t^k / tau)`

几何损失对候选边缘化，候选分歧自然形成分割不确定性。

#### C3. 可解释位姿协方差与闭环更新门控

从 SLCT 的加权正规方程获得局部 Fisher/Hessian：

`Sigma_T = sigma_r^2 (J^T W J + lambda I)^-1`

结合：

- 有效搜索线比例。
- 轮廓残差中位数与尾部比例。
- Hessian 条件数。
- 前景/背景概率间隔。
- 短时运动创新量。

形成姿态风险。几何更新采用稳健异方差损失：

`L = sum_t w_t E_q[L_sil(G,T_t,M_t^k)] + lambda_l L_lap + lambda_f L_flat + lambda_e L_edge`

其中 `w_t` 由不确定性决定，但必须设置下限和稳健核，防止模型通过无限增大方差逃避误差。

模型更新只有在保留帧上改善后验预测似然且网格有效性通过时才提交，否则回滚。

#### C4. 对象级期望信息增益关键帧

候选帧分数：

`A_t = Delta H(G) + beta Delta H(T_t) + gamma Coverage_t - eta Risk_t - rho Cost_t`

工程近似：

- 用渲染 Jacobian 与当前参数协方差估算 `log det` 信息增益。
- 用可见面覆盖增量衡量新几何证据。
- 用分割熵、位姿条件数和运动模糊惩罚风险。
- 用优化耗时估计计算成本。

这比固定 3 度阈值更有科学含义，并能验证“帧数-质量-耗时”Pareto 前沿。

#### C5. 长期对象记忆与无 GT 重定位

维护规范对象坐标中的稀疏记忆：

- 关键帧 RGB 特征和 Mask。
- 长程二维点轨迹。
- 通过当前几何反投影得到的 3D 锚点及置信度。
- 视角、可见性和描述子原型。

跟踪风险超过阈值时：

1. 暂停几何更新，避免污染。
2. 使用视频分割或点跟踪维持对象区域假设。
3. 将当前 2D 特征与高置信 3D 锚点匹配。
4. PnP/RANSAC 生成多个位姿假设。
5. 用轮廓、外观和运动一致性排序。
6. 仅在后验优势显著时恢复局部 SLCT 跟踪。

### 5.4 可行的技术实现路线

#### 阶段 0：可信基线，2-3 周

- 实现 `strict-causal` 与 `oracle-reset` 双协议。
- 修复原子批次通信，按 `frame_id` 对齐。
- 保存完整配置、环境、随机种子和逐帧 JSONL。
- 复现原论文 MOPED/RBOT 主表。
- 建立三次重复运行和离线统一评测。

这是所有后续结论的前置条件，不应与算法创新混在同一个消融中。

## 6. 实验设计

### 6.1 协议

必须固定三种输入设定，避免混合比较：

- `PF-0`：首帧框、首帧位姿、K；无额外参考帧。
- `PF-R`：在 PF-0 基础上增加 R 个带位姿参考帧。
- `CAD`：提供真实 CAD，只作为模型上界，不与 prior-free 方法混排。

所有主结果采用 `strict-causal`。`oracle-reset` 仅用于复现历史协议。

### 6.2 数据集

基础组：

- MOPED：真实未知对象、与原论文直接对比。
- RBOT：动态光、噪声、遮挡压力测试。
- BCOT：高精度姿态和更复杂运动。

扩展组：

- HO3D、YCBInEOAT 或同类手物交互序列：评估严重手遮挡。
- 自建小型 MoCap 数据：10-15 个未知对象，包含完全遮挡、出视野、快速运动、反光、低纹理和拓扑复杂物体。

如扩展数据集提供 RGB-D，算法仍只使用 RGB；深度只可用于几何评价和 RGB-D 方法的独立对照。

### 6.3 对比方法

- 原始 BIT：原协议和 strict-causal 两版。
- SLCT/SLOT + GT CAD：局部跟踪上界。
- Gen6D、OnePose++ 等参考图像方法。
- FoundationPose：CAD/训练先验组。
- BundleSDF、GTR、Point2Pose：RGB-D 组，单独列出输入模态。
- 简单基线：SAM 最高分、帧间 Mask 传播、固定角度关键帧。

公平性要求：

- 相同首帧初始化。
- 相同输入模态分组。
- 不把离线、多参考帧方法与 PF-0 直接宣称为同设定 SOTA。
- 公开所有失败序列，而不是只汇总成功对象。

### 6.4 指标

位姿：

- ADD(-S) AUC、5 cm/5 度成功率。
- 旋转和平移误差的中位数、95 分位数。
- 无重置序列生存率、首次失败时间、失败后漂移面积。
- 完全遮挡后的重定位成功率、恢复延迟和误恢复率。

几何：

- 对称对齐后的 Chamfer-L1/L2。
- F-score@不同阈值、法向一致性、完整度和精度。
- 轮廓 IoU 的已见视角与未见视角拆分。
- 拓扑正确率只用于支持拓扑变化的方法。

不确定性：

- 位姿 NLL、ECE、Brier score。
- 风险-覆盖曲线、AURC。
- 失败提前量：风险超过阈值到真实失败的帧数。
- 置信区间覆盖率。

效率：

- 跟踪 FPS、建模时间、峰值显存。
- 单次更新使用的关键帧数。
- 精度-耗时和质量-关键帧数 Pareto 曲线。

### 6.5 消融矩阵

按累加方式：

1. strict BIT。
2. + 原子通信与可复现日志。
3. + SAM 多候选。
4. + SLCT 位姿协方差。
5. + 异方差几何损失。
6. + 模型更新门控。
7. + 信息增益关键帧。
8. + 长期记忆重定位。

专项消融：

- 仅 SAM、仅 tracker、仅 render、完整不确定性。
- 硬 Mask、Top-1、Top-K 边缘化。
- 视角角度、覆盖增量、Fisher 信息增益。
- 无记忆、短期记忆、长期 2D-3D 记忆。
- 不同遮挡比例、Mask 腐蚀/膨胀、位姿扰动和运动模糊强度。

### 6.6 统计规范

- 每个随机组件至少 3 次运行，关键表建议 5 次。
- 报告均值、标准差和 95% bootstrap 置信区间。
- 序列级配对比较使用 Wilcoxon signed-rank 或配对 bootstrap。
- 多重比较使用 Holm-Bonferroni 校正。
- 同时报告效应量，不以单个 p 值代替实际提升。
- 阈值只在验证对象上选择，测试对象不得调参。

## 7. 第二研究方向：TopoBIT

如果目标是进一步冲击几何/图形方向，可在 P-BIT 建立可靠观测后研究 **TopoBIT: Evidence-Adaptive Topology for Prior-Free Tracking**。

研究问题：

> 如何在单目轮廓证据不足且带噪的条件下，只在证据充分时改变几何拓扑，同时保持实时跟踪所需的稳定显式表面？

可选实现：

- 外层使用可微 SDF 或 occupancy 表达拓扑。
- 内层维持可快速渲染的显式网格代理供 SLCT 使用。
- 依据多视角自由空间证据、轮廓矛盾和不确定性触发局部重网格。
- 对未观测区域保持高不确定性，不强行补全为确定表面。

该方向创新更强，但风险也更高：

- 单目轮廓无法可靠恢复凹陷和背面，必须严格区分“观测重建”和“先验补全”。
- 神经隐式或 3D foundation model 会削弱“training-free/prior-free”主张。
- 动态重网格会破坏 SLCT 局部颜色模型与顶点对应关系。

建议先完成 P-BIT，再把 TopoBIT 作为第二篇论文，而不是在第一篇中同时承担可靠性、重定位和任意拓扑。

## 8. 预期成果与论文标准

### 8.1 最低可发表结果

- strict-causal 下相对原始 BIT 显著降低首次失败率。
- 不确定性在独立测试对象上具有可接受校准误差。
- 使用更少关键帧达到相同或更高几何精度。
- 在人工遮挡和真实遮挡上显著提高恢复率。
- 公开区分 oracle-reset 与 strict-causal，完整披露失败。

### 8.2 顶会竞争力结果

建议目标，不作为预先承诺：

- strict-causal ADD(-S) AUC 相对提升 5-10 个点，或序列生存时间提升 30% 以上。
- 完全遮挡后的恢复成功率提高 20 个百分点以上，误恢复率低于 5%。
- 在相近几何质量下减少 30% 以上关键帧或建模时间。
- ECE 低于 0.05，风险-覆盖曲线明显优于单分数基线。
- 在至少三个公开数据集和一个真实压力测试集上保持一致趋势。

### 8.3 可能投稿方向

- CVPR/ICCV/ECCV：强调未知对象、概率闭环和长期恢复。
- ICRA/IROS/RA-L：强调在线性、遮挡恢复和机器人部署。
- TPAMI/TRO：在更广数据集、理论分析和长期实验后扩展。
- SIGGRAPH/TOG：仅当 TopoBIT 在几何表示和拓扑变化上形成实质方法贡献。

## 9. 执行优先级

P0，论文有效性：

1. 禁用首帧后的 GT 状态反馈。
2. 修复通信批次原子性和 frame ID 对齐。
3. 建立统一评测、日志和复现脚本。

P1，低风险研究增益：

4. SAM 多候选与观测置信度。
5. 位姿 Hessian/残差统计。
6. 加权几何优化、最佳模型和回滚。

P2，主论文创新：

7. 概率候选边缘化。
8. 信息增益关键帧。
9. 长期 2D-3D 记忆与重定位。

P3，第二论文：

10. 证据驱动的自适应拓扑。

最终建议是先把 BIT 从“能形成闭环”升级为“闭环可靠性可测、可解释、可控制”。这条路线同时利用现有代码资产、回应原论文公开局限，并与不确定性感知建图、长期对应和主动信息获取等前沿趋势形成明确交叉。
