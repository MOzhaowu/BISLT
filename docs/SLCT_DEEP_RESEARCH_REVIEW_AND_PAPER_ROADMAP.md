# SLCT 深度研究审查、改进路线与论文方案

## 1. 执行摘要

审查对象为 `/Users/bytedance/Desktop/SLCT-main` 当前源码快照。该目录不包含 `.git`，也没有完整数据集、预训练权重或历史实验产物，因此本文能够确认算法实现和评测逻辑，但不能独立复现论文数值。

SLCT 对应论文 **Pixel-Wise Weighted Region-Based 3D Object Tracking Using Contour Constraints**。它解决的是：

> 已知 CAD 模型、相机内参和首帧位姿时，如何仅用单目 RGB 视频实时跟踪弱纹理/无纹理刚体的 6DoF 位姿，并降低局部遮挡、颜色歧义和背景杂乱造成的错误优化梯度。

核心判断如下。

1. SLCT 是解析式、无需训练的模型驱动跟踪器，不是深度神经网络。其“模型架构”由 OpenGL 几何渲染、TCLC 局部颜色模型、轮廓搜索线、像素级加权区域似然和 SE(3) Gauss-Newton 优化组成。
2. 原始创新是有价值且自洽的：在轮廓法线方向显式搜索观测边界，并用边界颜色可信度和距离一致性给区域残差逐像素加权。
3. 该方法具有可解释、低数据依赖、适合弱纹理对象等优势，但本质仍是局部优化。对快速运动、完全遮挡、对称物体、前背景长期同色、光照突变和模型误差缺少系统处理。
4. 当前代码存在会影响实验可信度的问题：GT 失败重置、运行时间恒为 0、直方图时间一致性被错误清零、纯平移的 SE(3) 指数映射返回单位矩阵、无阻尼 Hessian 求逆、配置参数未实际生效。
5. 在 SRT3D、DeepAC、Large-Displacement Tracking、RNNPose、FoundationPose 和 Zero6DOT 之后，只调整固定权重或叠加普通 CNN 已不足以支撑顶会论文。
6. 推荐研究主线是 **U-SLCT: Uncertainty-Calibrated Hybrid Contour Tracking**：把轮廓对应从单点硬匹配升级为多假设概率分布，把解析 Hessian 转化为可校准位姿不确定性，并结合轻量学习边界证据、时序运动先验和风险触发重定位。

推荐的论文核心问题是：

> 能否在保留解析模型可解释性和边缘端效率的同时，显式建模轮廓对应、外观更新和位姿优化的不确定性，使单目 RGB 6DoF 跟踪在快速运动、遮挡和域变化下保持长期稳定，并在失败前给出可信风险？

## 2. 项目定位与任务假设

### 2.1 输入与输出

输入：

- 单目 RGB 图像序列。
- 精确或近似的三角网格 CAD 模型。
- 相机内参 `K`。
- 首帧之前一帧的 GT 位姿作为初始化。

输出：

- 每帧对象到相机的刚体变换 `T_cm ∈ SE(3)`。

源码默认采用 RBOT 设定：平移误差大于 50 mm 或旋转误差大于 5 度即判失败。

### 2.2 隐含假设

- 目标是刚体，CAD 与真实对象尺度一致。
- 帧间运动足够小，上一帧位姿位于当前目标的局部收敛域内。
- 目标轮廓附近前景和背景颜色分布存在一定差异。
- 相机畸变可忽略；代码构造了全零畸变系数，去畸变逻辑被注释。
- 可见轮廓对 6DoF 位姿提供足够约束。
- 目标不会长期完全离开视野，系统也不负责全局检测和重定位。

这些假设决定了 SLCT 更准确的定位是“逐帧局部位姿细化器”，而不是完整的长期对象跟踪系统。

## 3. 系统架构与数据流

### 3.1 模块划分

| 模块 | 主要文件 | 作用 |
|---|---|---|
| 应用与评测 | `src/app/run_on_video.cc` | 读取视频、GT、模型，运行跟踪并计算成功率 |
| 跟踪控制 | `src/mbt/tracker.cc` | 图像金字塔、直方图更新、对象管理 |
| SLCT 核心 | `src/mbt/tracker_slc.cc` | 轮廓匹配、权重、Jacobian/Hessian、位姿更新 |
| 搜索线 | `src/mbt/search_line.cc` | 提取渲染轮廓、估计法线、生成离散搜索线 |
| 外观模型 | `src/mbt/tclc_histograms.cc` | 每个模型顶点的时序一致局部前/背景直方图 |
| 渲染 | `src/mbt/view.cc` | OpenGL 离屏渲染 Mask、深度和反向深度 |
| 几何模型 | `src/mbt/model.cc` | Assimp 网格加载、归一化、VBO 和位姿状态 |
| 李群更新 | `src/mbt/transformations.cc` | 6D twist 到 SE(3) 的指数映射 |

### 3.2 单帧流程

1. 将当前 RGB 帧构造为 4 层金字塔。
2. 按 `1/4 -> 1/2 -> 1` 分辨率执行 `4 + 2 + 1` 次优化。
3. 根据当前姿态渲染对象 Mask 和深度。
4. 从 Mask 提取所有轮廓，每隔 2 个像素采样一个轮廓点。
5. 估计轮廓法线，并沿法线两侧构造长度为 8-12 像素的搜索线。
6. 对搜索线像素查询相邻 TCLC 直方图，得到前景概率 `p_f` 和背景概率 `p_b`。
7. 在搜索线上寻找使“左侧像背景、右侧像前景”最可信的观测轮廓点。
8. 根据轮廓颜色可信度和像素到匹配轮廓的距离构造权重。
9. 累积 6x6 近似 Hessian 和 6x1 梯度。
10. 左乘 SE(3) 增量更新对象姿态。
11. 跟踪结束后，用新姿态渲染的区域更新局部颜色直方图。

### 3.3 模型规模

每个模型顶点维护两个 `32^3 = 32768` 维浮点颜色直方图。若模型有 5000 个顶点，仅归一化前/背景直方图理论内存约为：

`5000 × 32768 × 2 × 4 bytes ≈ 1.31 GB`

这与 README 建议的 4000-7000 顶点组合后内存代价很高。虽然运行时只选择最多约 100 个轮廓附近中心更新，但完整矩阵仍按全部简单顶点分配。该表示是效率和可扩展性的主要瓶颈之一。

## 4. 算法原理

### 4.1 时序一致局部颜色模型

每个可见模型顶点 `v_i` 对应局部前景和背景直方图：

`H_i^F(c), H_i^B(c)`

当前像素颜色 `c_x` 的局部前景后验近似为：

`P(F | c_x, i) = H_i^F(c_x) / (H_i^F(c_x) + H_i^B(c_x) + ε)`

同一搜索线像素可能落入多个局部直方图半径，代码对相关后验做算术平均。直方图采用指数滑动更新，前景和背景设计学习率分别为 0.1 和 0.2。

优点：

- 相比全局直方图，局部模型能表达对象不同区域的外观差异。
- 直方图绑定 3D 顶点，理论上可跨视角保持外观记忆。
- 无需训练，适配新对象。

局限：

- RGB 量化对光照、白平衡、反光和曝光变化敏感。
- 每通道 32 bins 导致极高维稀疏表示。
- 直方图更新依赖当前预测 Mask，姿态错误会把背景写入前景模型，形成自污染。
- 对未初始化或缺乏颜色差异的区域没有可靠退化策略。

### 4.2 轮廓搜索线与对应点

渲染轮廓点 `q_r` 的法线方向上生成离散搜索线 `L_r`。对候选位置 `c`，使用前后各 3 个像素的概率乘积：

- `P_C`：候选左侧为背景、右侧为前景。
- `P_F`：两侧均为前景。
- `P_B`：两侧均为背景。

只有 `P_C > P_F` 且 `P_C > P_B` 的候选才可作为轮廓，并选择负对数代价最小者。该策略把轮廓定位从局部梯度峰值改成前/背景统计变化，更适合弱纹理对象。

局限：

- 使用硬阈值 `|p_f(c+1)-p_f(c-1)| > 0.5`。
- 只保留单个最佳点，丢失多峰、对称和遮挡情况下的多模态信息。
- 前后各 3 个像素使用乘积，任一低概率会使分数快速塌缩。
- 搜索长度固定，无法自适应帧间运动和位姿不确定性。

### 4.3 像素级轮廓约束权重

若搜索线找到轮廓点 `e_r`，轮廓颜色权重为：

`w_e = exp(1.2 (score_r - 1))`

距离权重为：

`w_d(x) = exp(-0.25 ||x - e_r||)`

最终：

`w_a(x) = w_e w_d(x)`

若没有找到轮廓，使用较低固定颜色权重和固定距离衰减。其作用是降低不可信轮廓附近区域像素对位姿更新的影响。

贡献价值：

- 将显式轮廓证据嵌入区域似然，而不是简单相加两个独立能量项。
- 权重具有局部空间含义，可针对同一帧不同轮廓区域自适应。
- 对遮挡和颜色歧义产生的错误方向梯度有抑制作用。

局限：

- 颜色和距离权重参数固定，未做概率校准。
- `ColorWeight(float c, ...)` 实际忽略参数 `c`。
- 未匹配搜索线仍参与优化，固定权重 0.1 可能在大量遮挡时累积错误梯度。
- 代码内保留多个不可达权重公式，实验版本难以追溯。

### 4.4 区域能量与解析优化

对搜索线像素，使用平滑 Heaviside 函数：

`H(d) = -atan(s d) / π + 1/2`

前背景混合概率：

`e(x,T) = H(d(x,T)) (p_f - p_b) + p_b + ε`

目标是最大化像素观测似然，代码利用链式法则计算轮廓法线方向距离对 SE(3) twist 的 Jacobian，并累积加权正规方程：

`H_T = Σ w(x) J_x^T J_x`

`g_T = Σ w_a(x) J_x^T r_x`

位姿更新：

`T <- Exp(-H_T^{-1} g_T) T`

系统分别使用正向和反向深度对前后可见表面构造 Jacobian，这是完整轮廓几何约束的一部分。

优点：

- 全解析梯度，不依赖自动微分和对象特定训练。
- 6x6 系统求解开销小。
- 粗到细策略扩大平移方向的局部收敛域。

局限：

- 直接 Cholesky 求逆，没有 Levenberg-Marquardt/Tikhonov 阻尼。
- 不检查 Hessian 是否正定、条件数是否过高或更新是否降低能量。
- 没有 line search、trust region 或步长裁剪。
- 图像金字塔只能有限缓解平移，对大角度面外旋转帮助较弱。
- 没有显式运动模型，上一帧位姿是唯一初始化。

## 5. 原始贡献与当前竞争位置

### 5.1 原论文贡献

根据论文和源码，SLCT 的三项主要贡献可表述为：

1. 提出基于轮廓搜索线的稀疏区域代价，避免在全图计算 signed distance transform。
2. 提出利用局部前/背景概率搜索观测轮廓的策略，以识别遮挡和颜色歧义区域。
3. 提出颜色可信度与轮廓距离联合的像素级权重，并将其直接纳入区域优化。

论文公开摘要称其在局部遮挡和颜色歧义场景优于当时区域跟踪方法：

- https://pubmed.ncbi.nlm.nih.gov/34077359/

### 5.2 相对后续工作的不足

- **SRT3D, IJCV 2022**：提供更完整的稀疏概率对应线模型、全局/局部不确定性和平滑尺度空间，并使用正则化 Newton 优化。
- **ICG, CVPR 2022**：融合区域和深度对应，在单 CPU 核报告约 1.3 ms/帧；其纯区域模块也在 RBOT 上表现强。
- **Large-Displacement Tracking, ECCV 2022**：把面外旋转做非局部搜索，针对 SLCT 类方法的大位移局部最优问题。
- **DeepAC, ICCV 2023**：用轻量网络预测轮廓应如何移动，保留几何优化并端到端训练，在移动端实时。
- **RNNPose, TPAMI 2024**：循环估计对应场并结合可微 LM，使用一致性机制降低遮挡错误对应权重。
- **FoundationPose, CVPR 2024**：统一新对象估计与跟踪，但依赖 RGB-D 和较强学习/算力。
- **OmniPose6D, IROS 2025**：强调动态场景短期 RGB 跟踪、合成数据规模和不确定性感知关键点。
- **Zero6DOT, TCSVT 2025**：仅初始 Mask、无 CAD 的单目 RGB 长程对应跟踪，报告 8 Hz。

因此，新工作不能把“搜索线、局部权重、轮廓网络、单一不确定性”本身作为 novelty，必须形成更完整的新问题和技术闭环。

## 6. 源码级风险与实验有效性

### 6.1 P0：会改变研究结论的问题

#### 6.1.1 GT 失败恢复

`src/app/run_on_video.cc:83-85` 每帧使用 GT 判断是否超过 5 cm/5 度，并在失败时立即把姿态设置为当前 GT。

影响：

- 报告的是带 oracle reset 的局部成功率，不是严格因果的长期跟踪。
- 失败后漂移不会传播到颜色模型和后续帧。
- 无法评价自主恢复能力、首次失败时间和序列生存率。

正确做法是保留两套协议：

- `oracle-reset`：复现历史 RBOT 结果。
- `strict-causal`：仅首帧使用 GT，之后 GT 只用于离线评分。

#### 6.1.2 TCLC 时间一致性被清零

`src/mbt/tclc_histograms.cc:683-684` 每帧把 `normalizedFG/BG` 的前 `N` 行清零，但后续更新按真实顶点 ID `cID` 写入。

影响：

- 一部分历史顶点外观会被无条件删除。
- “temporally consistent” 的实现与算法声称不一致。
- 清零的是前 N 个顶点，不一定是当前更新的 N 个顶点，行为依赖网格顶点排序。

应只清零当前帧临时计数 `notNormalizedFG/BG`，保留归一化历史模型。

#### 6.1.3 纯平移增量被丢弃

`src/mbt/transformations.cc:148-152` 在旋转 twist 接近 0 时直接返回单位矩阵，也丢弃了非零平移 `v`。

影响：

- 纯平移或近纯平移的 Gauss-Newton 增量可能不生效。
- 小旋转下数值行为不连续。

应实现 SE(3) 指数映射在 `θ -> 0` 时的稳定级数展开，至少返回平移。

#### 6.1.4 无阻尼 Hessian 求逆

`src/mbt/tracker_slc.cc:440` 直接计算 `wJTJ.inv(DECOMP_CHOLESKY)`，未检查求逆是否成功。

影响：

- 遮挡、对称、远距离和轮廓过少时 Hessian 易退化。
- NaN 只会在后续 GT 判失逻辑中被发现。
- 无法获得可信协方差和风险。

建议采用阻尼 LM、特征值截断或 SVD，并记录条件数、最小特征值和实际/预测下降比。

### 6.2 P1：复现和归因问题

- `all_time` 从未累计，`avg_rt` 恒为 0。
- `tracker_mode` 被解析但 `Tracker::GetTracker()` 无条件返回 `SLCTracker`。
- `alpha_fg/alpha_bg` 被解析，但更新函数硬编码 0.1/0.2。
- `line_len/sl_seg/hist_rad/hist_offset/search_rad` 多数配置值被固定常数覆盖。
- `check_lost` 参数传入 `EstimatePoses()` 后未使用。
- 相机去畸变被注释，真实相机实验可能出现系统性轮廓误差。
- 仅提供一个 Windows 绝对路径配置，缺少批量评测脚本。
- 项目无测试、无固定依赖版本、无随机种子和逐帧诊断日志。
- `acos((trace-1)/2)` 未 clamp 到 `[-1,1]`，浮点误差可产生 NaN。

### 6.3 P2：效率和工程问题

- 全量 `V × 32768 × 2` 浮点直方图内存过大。
- 搜索线每像素遍历全部当前直方图中心，复杂度近似 `O(R L H)`。
- 多处逐像素 `cv::Mat::at` 和完整 Mask 转换未向量化。
- 每次迭代包含多次 GPU 渲染到 CPU 下载，可能受同步开销限制。
- `static` 搜索线临时向量使并行化存在数据竞争风险。
- 线程数直接设为中心数量，空中心和过多小任务都缺少专门处理。

## 7. 场景泛化与失败模式

| 场景 | 预期表现 | 主要原因 | 优先改进 |
|---|---|---|---|
| 弱纹理、前背景颜色不同 | 强 | 区域统计适合无纹理对象 | 保持解析区域分支 |
| 局部遮挡 | 中等偏强 | 轮廓可信度可降权 | 遮挡概率与硬拒绝 |
| 前背景同色 | 弱 | `p_f ≈ p_b`，梯度退化 | 深度特征/边缘/语义特征融合 |
| 动态光照、曝光跳变 | 弱 | RGB 直方图域漂移 | Lab/色度不变量、双时间尺度更新 |
| 镜面、透明对象 | 很弱 | 颜色统计不稳定，轮廓有伪边缘 | 学习轮廓证据、偏振/事件等扩展 |
| 快速运动/低帧率 | 很弱 | 固定短搜索线和局部优化 | 运动预测、多假设、非局部旋转 |
| 完全遮挡/出视野 | 失败 | 无检测和长期记忆 | 风险状态机与重定位 |
| 对称对象 | 弱且过度自信 | 单峰 SE(3) 优化 | 对称等价类与多模态后验 |
| CAD 有误/粗模型 | 弱 | 轮廓系统偏差 | 几何容差场或轮廓偏置联合估计 |
| 小目标/远距离 | 弱 | 轮廓采样和 Hessian 退化 | 尺度自适应采样与不确定性 |
| 多对象互遮挡 | 有限 | 仅模型间深度遮挡过滤 | 场景级可见性图和实例 Mask |

## 8. 推荐主线：U-SLCT

### 8.1 方法概述

U-SLCT 由五个相互依赖的模块组成：

1. **概率轮廓对应**：搜索线保留 Top-K 候选和无匹配假设，不再硬选单点。
2. **学习-解析混合证据**：轻量网络预测候选边界似然、遮挡概率和外观可靠性，几何 Jacobian 仍解析计算。
3. **可校准 SE(3) 不确定性**：从阻尼 Hessian、残差尺度和对应熵获得位姿协方差。
4. **风险控制的时序外观更新**：只用高置信可见区域更新短期/长期双记忆，阻断自污染。
5. **风险触发的多假设恢复**：局部跟踪失去可观测性时，切换到运动先验和关键帧 2D-3D 重定位。

### 8.2 C1：概率搜索线

对搜索线 `L_r` 的候选边界位置 `z_r` 建模：

`p(z_r=c | I,T,G) ∝ p_color(c) p_edge(c) p_visibility(c) p_motion(c)`

增加 `z_r = ∅` 表示该搜索线被遮挡或无有效边界。优化时边缘化对应：

`L(T) = -Σ_r log Σ_c p(z_r=c) p(I_r | T,z_r=c)`

工程上可用 Top-K 混合 Gauss-Newton 或 EM：

- E 步：根据当前位姿计算候选责任度。
- M 步：按责任度累积解析 Jacobian/Hessian。

Novelty 不在“多候选”本身，而在把轮廓对应熵、遮挡空假设和位姿协方差统一起来，并证明其校准与长期稳定性的关系。

### 8.3 C2：轻量轮廓证据网络

网络输入建议限制在局部 strip：

- 当前 RGB 搜索线邻域。
- 渲染 Mask/法线/深度。
- 前背景统计概率。
- 前一帧对应与光流或运动预测。

输出：

- 每个候选位置的边界 logits。
- 遮挡/无对应概率。
- 外观可靠性或异方差尺度。

可用小型 1D CNN、MobileNet strip encoder 或 tiny Transformer。训练不直接回归 6DoF，而是学习“哪条对应可信”，使对象几何和解析优化继续承担精确位姿求解。

训练目标：

`L = L_boundary + λ_occ L_occlusion + λ_cal L_calibration + λ_pose L_pose`

- `L_boundary`：GT 投影轮廓位置的交叉熵或分布回归。
- `L_occlusion`：可见性监督。
- `L_calibration`：Brier/NLL 或分桶校准项。
- `L_pose`：可微 LM 后的 ADD(-S) 或投影误差。

### 8.4 C3：位姿不确定性与可观测性

阻尼正规方程：

`H_λ = J^T W J + λ diag(J^T W J) + εI`

局部协方差：

`Σ_T = σ_r^2 H_λ^{-1}`

其中 `σ_r` 使用 MAD 或 Student-t 残差尺度估计。风险特征包括：

- `log det Σ_T`。
- Hessian 条件数和最小特征值。
- 搜索线候选平均熵。
- 无匹配/遮挡搜索线比例。
- 实际能量下降与模型预测下降之比。
- 运动创新 Mahalanobis 距离。

使用温度缩放、isotonic regression 或小型校准头，在独立验证对象上把风险映射为下一帧失败概率。

### 8.5 C4：安全外观更新

为每个顶点维护：

- 慢速长期颜色/特征原型。
- 快速短期适应模型。
- 更新次数和不确定性。

更新门控：

`a_i = visibility_i × pose_conf × boundary_conf × novelty_gate`

只有 `a_i > τ` 的区域更新；全局风险高时冻结所有外观更新。短期模型可适应光照，长期模型用于恢复，避免遮挡期间被污染。

进一步可将 32768 维 RGB 直方图替换为：

- 16x16 的 `ab` 色度直方图加亮度统计。
- 稀疏哈希直方图。
- 8-32 维在线高斯混合或小型原型集合。
- 低维自监督视觉特征原型。

### 8.6 C5：时序预测与恢复

正常状态：

- 在 SE(3) 切空间使用常速度或 learned motion prior 预测。
- 搜索线长度由投影协方差自适应确定。

风险状态：

- 保留多个面外旋转和深度假设。
- 暂停外观更新。
- 用关键帧描述子匹配获得 2D-3D 对应。
- PnP/RANSAC 或轮廓后验生成候选位姿。
- 由概率轮廓似然和运动先验排序。

恢复状态：

- 要求连续若干帧后验稳定才恢复模型更新。
- 记录误恢复率，而不只记录恢复成功率。

## 9. 备选创新方向

### 9.1 Rough-SLCT：粗 CAD 与形状不确定性

研究问题：

> 当 CAD 只近似真实对象时，如何区分位姿误差和模型轮廓偏差？

方法：

- 为模型轮廓点学习/估计视角相关法线偏置。
- 联合优化低维形变基和位姿。
- 对形变使用零均值、平滑和跨视角一致性先验。
- 将形状不确定性加入搜索线宽度和 Hessian。

价值：比精确 CAD 假设更接近工业资产、磨损零件和快速扫描模型。风险是位姿与形变耦合，需要多视角可观测性分析。

### 9.2 Event-SLCT：事件相机与 RGB 融合

事件对快速运动和高动态范围更稳健。可用事件时间表面提供短时轮廓似然，RGB 维护长期外观：

`p(z|I,E) ∝ p_color(z|I) p_event(z|E)`

适合高速机械、无人机和低照度 AR，但需要新硬件和同步数据，工程成本较高。

### 9.3 Tactile-SLCT：手内操作的视觉-触觉约束

将接触点、夹爪运动学和不可穿透约束作为 SE(3) 因子，补偿手遮挡。其研究贡献应是接触可行域与轮廓不确定性的统一优化，而不是简单传感器拼接。

### 9.4 Active-SLCT：主动视角控制

把位姿协方差用于相机/机械臂下一视角规划：

`a* = argmax_a E[log det Σ_T - log det Σ_T' | a] - β cost(a)`

这可把被动跟踪扩展为主动感知，适合机器人检查和装配，但已是不同任务设定，建议作为后续论文。

## 10. 效率优化路线

### 10.1 算法级

1. 用可见轮廓长度和协方差自适应分配搜索线，而不是固定每 2 像素采样。
2. 只在高信息轮廓段计算候选，按法线方向和 Hessian 增益做预算选择。
3. 缓存渲染轮廓的 3D 点、法线和深度，减少每次迭代 GPU-CPU 同步。
4. 使用增量外观更新，只处理本帧可见顶点。
5. 在能量下降不足时早停，替代固定 7 次迭代。

### 10.2 数据结构

1. 将稠密 32768-bin 直方图改成稀疏计数或低维色度模型。
2. 使用结构化数组连续存储搜索线、概率和 Jacobian。
3. 建立图像空间网格索引，使每个像素只访问邻近直方图中心，避免遍历全部中心。
4. 对颜色 bin 预计算整帧索引。

### 10.3 并行与部署

- CPU：轮廓线级并行、SIMD、TBB/OpenMP，避免每中心一个线程任务。
- GPU：批量渲染、概率查询和 Jacobian reduction 放在同一设备。
- 移动端：FP16/INT8 量化轻量证据网络，解析优化保持 FP32。
- 目标报告：桌面 CPU、嵌入式 CPU、移动 GPU 三个平台的延迟分解和能耗。

模型压缩只针对新增的学习证据网络：

- knowledge distillation。
- structured channel pruning。
- INT8 quantization-aware training。
- 固定长度 strip batching。

## 11. 完整实验方案

### 11.1 数据集与协议

基础数据集：

- **RBOT**：与原论文直接对比，覆盖 regular、dynamic light、noise、occlusion。
- **OPT**：连续位姿精度和不同对象。
- **BCOT**：高精度、多运动模式和真实场景。
- **YCB-Video / YCBInEOAT**：杂乱、多对象和机器人操作。
- **HO3D**：手物交互和严重遮挡；只选择具备可用 CAD/位姿的序列。

新增压力集建议：

- 12-20 个从未参与训练的对象。
- 受控改变遮挡比例、角速度、曝光、模糊、前背景色差和 CAD 扰动。
- 每种因素至少 3 个强度，因素组合单独测试。
- RGB-D 或 MoCap 只生成 GT，算法输入仍为 RGB。

协议：

1. `oracle-reset`：历史可比性。
2. `strict-causal`：主论文结果，仅首帧 GT。
3. `recovery`：明确插入完全遮挡/出视野，评价自主恢复。
4. `cross-object`：训练对象、验证对象、测试对象严格不重叠。
5. `cross-domain`：合成训练到真实测试、室内到工业场景。

### 11.2 对比方法

解析/优化组：

- 原始 SLCT。
- RBGT。
- SRT3D。
- ICG 的 RGB region modality。
- Large-Displacement 3D Tracking。

学习/混合组：

- DeepAC。
- RNNPose。
- PoseRBPF 或同类概率跟踪器。

开放世界组单列，不直接宣称同设定公平：

- FoundationPose（RGB-D）。
- Zero6DOT（无 CAD、初始 Mask）。
- GSGTrack（联合跟踪与重建）。

所有方法应按输入模态、是否需要 CAD、是否对象特定训练、是否使用深度、是否允许 GT reset 分组。

### 11.3 指标

精度：

- 5 cm/5 度成功率。
- ADD(-S) AUC。
- BOP 的 VSD、MSSD、MSPD 或 AR。
- 旋转/平移误差中位数和 95 分位数。

长期性：

- 首次失败时间。
- 无重置序列生存率。
- 轨迹误差积分。
- 连续失败最长长度。
- 恢复成功率、恢复延迟、误恢复率。

不确定性：

- pose NLL。
- 置信椭球覆盖率。
- ECE 和 Brier score。
- 风险-覆盖曲线与 AURC。
- 失败预警提前量。

效率：

- 端到端 FPS 和 p50/p95 延迟。
- 渲染、对应、网络、求解、外观更新的分项耗时。
- CPU/GPU/内存峰值。
- 每帧能耗和模型大小。

### 11.4 核心消融

基线修复消融：

1. 原始源码。
2. + TCLC 清零修复。
3. + 正确 SE(3) exp。
4. + 阻尼 LM 与数值检查。
5. + strict-causal 协议。

方法累加消融：

1. 修复后的 SLCT。
2. + Top-K 概率对应。
3. + 空对应/遮挡假设。
4. + 轻量边界证据网络。
5. + 位姿协方差。
6. + 风险门控双外观记忆。
7. + 自适应搜索范围。
8. + 多假设恢复。

专项消融：

- 手工颜色、手工边缘、学习证据、完整融合。
- 硬 argmax、soft expectation、Top-K EM。
- 单一高斯和对称多模态后验。
- 固定搜索线与协方差驱动搜索线。
- 单时间尺度和双时间尺度外观。
- Hessian-only 风险、network-only 风险、融合风险。
- RGB 直方图、Lab 色度、稀疏直方图、低维特征原型。

### 11.5 鲁棒性曲线

不能只报告四个 RBOT 场景均值，应画连续退化曲线：

- 遮挡面积：0%-90%。
- 角速度和帧间旋转。
- 平移速度和目标像素位移。
- Gaussian/Poisson 噪声。
- 运动模糊核长度。
- 曝光和色温偏移。
- 前背景颜色距离。
- CAD 顶点噪声、尺度误差和局部缺失。
- 相机内参扰动。

报告每种扰动下精度、校准和延迟的联合变化。

### 11.6 统计规范

- 随机训练至少 3 个种子，核心结论建议 5 个。
- 序列级 bootstrap 95% 置信区间。
- 同序列方法比较使用配对 bootstrap 或 Wilcoxon signed-rank。
- 多重比较采用 Holm-Bonferroni。
- 报告效应量，不只报告 p 值。
- 所有阈值只在验证对象上选择。

## 12. 论文叙事与贡献表述

### 12.1 推荐标题

**U-SLCT: Uncertainty-Calibrated Hybrid Contour Tracking for Robust Monocular 6DoF Object Pose**

或：

**Knowing When Contours Fail: Calibrated Correspondence Uncertainty for Long-Term Monocular 6DoF Tracking**

### 12.2 论文主张

现有轮廓/区域跟踪器通常把轮廓对应当作确定观测，并持续用当前位姿更新外观。这在遮挡、颜色歧义和快速运动下会同时造成错误优化与模型污染。U-SLCT 将搜索线对应建模为包含遮挡空假设的概率分布，从解析优化中恢复可校准位姿不确定性，再利用该不确定性控制外观更新、搜索范围和重定位。系统因此不仅提高平均精度，还能在严格无 GT 重置协议下延长生存时间并提前预测失败。

### 12.3 三项核心贡献

1. **Probabilistic contour correspondence**：提出带多候选和无匹配假设的搜索线后验，通过混合/EM 解析优化保留轮廓多模态信息。
2. **Calibrated pose and appearance uncertainty**：联合对应熵、稳健残差和阻尼 Hessian 构造 SE(3) 风险，并用其阻断时序外观自污染。
3. **Risk-aware long-term tracking**：用不确定性自适应搜索与触发多假设恢复，在 strict-causal、完全遮挡和跨对象设置下验证长期鲁棒性与失败预警能力。

效率压缩应作为第四项工程贡献，而不是替代前三项方法创新。

### 12.4 论文结构

1. **Introduction**：局部轮廓对应的确定性假设和自污染问题。
2. **Related Work**：解析区域跟踪、学习式姿态细化、概率跟踪、长期恢复。
3. **Preliminaries**：SLCT 搜索线区域似然和 SE(3) 优化。
4. **Method**：
   - 概率轮廓对应。
   - 学习-解析证据融合。
   - 位姿协方差与校准。
   - 风险门控外观更新。
   - 长期恢复。
5. **Experiments**：
   - 协议与公平分组。
   - 主结果。
   - 消融。
   - 鲁棒性与校准。
   - 效率和部署。
6. **Limitations and Ethics**：CAD 依赖、对称不可辨识、透明对象和误恢复风险。
7. **Conclusion**。

## 15. 投稿定位与成功条件

### 15.1 目标 venue

- CVPR/ICCV/ECCV：学习-解析混合、多模态不确定性、跨对象长期跟踪。
- ICRA/IROS/RA-L：严格在线、机器人遮挡恢复和边缘部署。
- TPAMI/TRO：在会议版本基础上增加理论、更多传感器/数据集和长期实验。
- TVCG/ISMAR：突出移动 AR 的低延迟、稳定性和失败感知。

### 15.2 顶会级最低证据

- 至少 3 个公开数据集和 1 个受控压力集。
- 主表使用 strict-causal，无后续 GT 干预。
- 对原始 SLCT、SRT3D、DeepAC 和大位移方法有公平比较。
- 在快速运动和遮挡上有一致提升，而不是只提升平均 RBOT 成功率。
- 不确定性校准和失败预测有独立指标。
- 延迟保持实时，新增网络适合边缘部署。
- 公开修复前后结果，避免把实现 Bug 修复包装成算法 novelty。

建议目标值只作为项目管理门槛：

- strict-causal 首次失败时间提升 30% 以上。
- 遮挡后恢复成功率提升 20 个百分点以上。
- 误恢复率低于 5%。
- 相同精度下延迟不高于 DeepAC/SRT3D 可接受区间。
- ECE 低于 0.05 或显著优于 Hessian-only/network-only 风险。

## 16. 最终优先级

P0，研究有效性：

1. 禁止首帧后的 GT 状态反馈。
2. 修复 TCLC 历史模型清零。
3. 修复 SE(3) 纯平移。
4. 修复计时、配置和求解稳定性。

P1，低风险论文增益：

5. Top-K/空假设概率对应。
6. 阻尼 Hessian 协方差和风险校准。
7. 风险门控双外观记忆。
8. 协方差驱动搜索范围。

P2，主论文竞争力：

9. 轻量学习边界/遮挡证据。
10. 严格跨对象训练与 sim-to-real。
11. 风险触发长期重定位。

P3，后续增长点：

12. 粗 CAD 联合形变。
13. 事件或触觉融合。
14. 主动视角规划。

最终建议不是继续把 SLCT 当作一个固定权重的 2021 基线，而是利用它独有的解析结构，把每条搜索线转化为可解释、可校准、可拒绝的概率观测。这样既能保留无需对象特定训练和实时优化的优势，也能形成区别于纯深度姿态回归、纯区域跟踪和开放世界重建方法的明确研究贡献。
